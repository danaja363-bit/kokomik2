# 📚 Kokomik2 - Web Baca Manga

Web baca manga seperti MangaDex, dengan backend Node.js + Express + SQLite dan frontend HTML/CSS/JS.

## ✨ Fitur

- 🔍 Cari manga berdasarkan judul, author, genre
- 📖 Baca chapter dengan navigasi keyboard (← →)
- 👤 Register & Login (JWT authentication)
- 🔖 Bookmark manga favorit
- ⚙️ Admin panel untuk CRUD manga & upload chapter
- 📱 Responsive di mobile & desktop

## 🛠️ Tech Stack

- **Backend**: Node.js, Express, better-sqlite3, JWT, Multer
- **Frontend**: HTML, CSS, Vanilla JavaScript
- **Database**: SQLite
